# The-effect-of-age-and-condition-on-transcript-errors
A study using deeply sequenced RNA samples to examine transcription errors across age and genomic condition in Drosophila melongaster.

The data preparation folder contains two pipelines, one for creating VCF files from RNA seq data using Freebayes, and a second one for calling and filtering transcript mismatches from those VCF files. 
Data analysis contains the script for the statistical analysis that gave the numbers used in the manuscript.
The figures folder contains the scripts for generating the manuscript figures, including supplementary figures with the exception of S1. 

Data analysis and Figures contain results from the Data_preperation that are needed to run those scripts.
